# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in WireManager, please do not
open a public GitHub issue.

Instead, report the vulnerability privately to the project maintainer at [security@netrod.xyz](mailto:security@netrod.xyz).

Please include:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any relevant logs or proof of concept

We will review security reports and work to address confirmed
vulnerabilities as soon as reasonably possible.
