# Contributing to WireManager

Thank you for your interest in WireManager!

## ⚠️ External Pull Requests Policy

**WireManager does not accept external Pull Requests (PRs).**

The codebase, design, and architecture are maintained directly by the author. Any external Pull Requests submitted to this repository will be closed.

## 💡 How to Contribute: Open a Ticket / Issue

We actively encourage and appreciate community feedback! The best way to contribute is by opening an issue on GitHub:

- **Bug Reports**: Encountered an error, crash, or unexpected behavior with WireGuard or firewall rules? Open a bug issue detailing your environment, steps to reproduce, and diagnostic logs.
- **Feature Requests**: Have an idea for a new capability, protocol support, or dashboard improvement? Open a feature request explaining your use case.
- **Security Disclosures**: Found a potential security issue? Report it responsibly via GitHub Private Vulnerability Reporting or contact the maintainer directly before public disclosure.

For complete guidelines on gathering logs, reporting bugs, and setting up a local reproduction environment, please refer to the [official Contributing Documentation](https://gwsimorod.github.io/WireManager-docs/docs/development/contributing).
